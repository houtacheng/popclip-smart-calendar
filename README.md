# 智能日曆助手 (Smart Calendar Assistant for macOS)

[![macOS](https://img.shields.io/badge/platform-macOS-lightgrey.svg)](https://apple.com/macos)
[![PopClip](https://img.shields.io/badge/PopClip-Extension-blue.svg)](https://popclip.app/)
[![Apple Calendar](https://img.shields.io/badge/Calendar-Apple-red.svg)](https://apple.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

專為 Mac 使用者打造的**「智能自然語言訊息轉 Apple 日曆」**外掛。
無論是在通訊軟體、Slack、電子郵件或網頁上看到活動通知，只要**反白選取文字**，即可一鍵將行程精準加入 Apple 內建日曆！

---

## 🌟 核心特色 (Key Features)

* 🌐 **多時區智能辨識**：
  若通知中並列多個時區（例如「紐約 20:00 / 倫敦 01:00 / 台灣 08:00」），**自動優先鎖定紐約（美東時間）**，省去手動換算時差的困擾。
* 📆 **跨日與整天行程辨識**：
  支援 `10/12-10/18 設計工作坊`、`10/12-18 架構研討週` 等無指定具體時分的格式，自動建立為跨日或單日「整天行程 (All-Day Event)」。
* 📋 **多筆行程批次匯入（雙模式確認）**：
  * **單筆行程**：彈出 Apple 日曆原生預覽編輯視窗供您審查後按確定。
  * **多筆行程**：自動逐行解析，並先跳出 macOS 原生清單視窗條列出所有行程與日期，點擊「確認全部加入」一次性整批匯入！點擊「取消」則完全不寫入。
* ⏰ **自然語言與口語時間**：
  完整支援「今天」、「明天」、「後天」、「下週五」、「早上 1000-1030」、「下午 2 點半」、「晚上 8 點」等多種日常書寫習慣。
* 🏷️ **括號標題智能提取**：
  優先識別 `【...】`、`[...]`、「...」 等活動主題括號。即使標題含有月份（如 `【10月專案進度交流會】`），也不會被誤判為時間行。
* 🔒 **100% 本機執行，無雲端依賴**：
  不依賴任何外部雲端 LLM API（零 Token 費用、零隱私洩漏風險），在 Mac 本機 0.1 秒極速解析。

## 📦 安裝說明 (Installation)

本專案提供 **兩種安裝方式**，可依個人習慣選擇：

### 方式一：PopClip 使用者（最推薦 ⭐️）
1. 至本專案的 [Releases](releases) 頁面或根目錄下載 **`SmartCalendar.popclipextz`**。
2. **雙擊打開檔案**，PopClip 會彈出安裝確認框。
3. 點擊 **「Install」** 即安裝完成！
4. **使用方法**：反白任何通知文字 ➔ 點擊 PopClip 出現的 **日曆圖示**。

---

### 方式二：免裝 PopClip（Mac 原生右鍵快速動作 / 服務）
即使沒有購買 PopClip，也能直接享有完整功能：
1. 下載 **`智能加入日曆.workflow`**。
2. **雙擊打開檔案**，系統會提示「是否安裝此快速動作」，點擊 **「安裝 (Install)」**。
3. **使用方法**：
   * 反白選取任何文字。
   * **按滑鼠右鍵** ➔ 選擇 **「快速動作」**（或「服務」）➔ 點擊 **「智能加入日曆」**。

> **💡 進階技巧：設定專屬鍵盤快捷鍵**
> 打開 Mac「系統設定」➔「鍵盤」➔「鍵盤快速鍵...」➔ 點選「服務」➔ 展開「一般」找到「智能加入日曆」，為它綁定一組快捷鍵（例如 `Command + Shift + C`），反白後按下快速鍵即可一秒直達！

## 🧪 支援測試範例 (Test Cases)

您可以選取以下任何文字進行測試：

#### 1. 跨時區會議通知
```text
【Q4 跨國產品開發交流會】

*主持人：Alex
*與會人員：設計組、前端組、後端團隊

*會議時間：
紐約 10/15(四) 20:00
倫敦 10/16(五) 01:00
台灣 10/16(五) 08:00
```
* **結果**：活動標題為 `Q4 跨國產品開發交流會`，時間為 `10/15 晚上 8:00 - 9:00 (紐約時間)`。

#### 2. 多筆跨日整天行程（批次匯入）
```text
10/12-10/18 產品設計工作坊
10/12-10/17 前端架構重構週
10/11 季度專案檢討會
10/11-10/17 新人技術培訓營
```
* **結果**：彈出確認彈窗，條列出 4 筆行程與各自的跨日全天時間，點擊確認後一次性寫入 Apple 日曆。

#### 3. 口語化與連字時間
```text
明天早上1000-1030團隊技術研討。
```
* **結果**：活動標題為 `團隊技術研討`，日期為明天，時間為 `10:00 - 10:30`。
